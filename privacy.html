Politique de confidentialité – Johan Automations

Cette application est utilisée uniquement par son auteur, Johan Souplis, sur ses propres comptes Google.

Services API de YouTube. Cette application utilise les services API de YouTube pour publier des vidéos sur la chaîne YouTube de son auteur (« Investisseur Logique »). En l'utilisant, vous acceptez les Conditions d'utilisation de YouTube. Voir aussi les Règles de confidentialité de Google.

Données consultées : e-mails (lecture seule), agenda, fichiers Drive, informations de la chaîne YouTube et envoi de vidéos. Ces données servent uniquement à automatiser les tâches de l'auteur. Elles ne sont ni stockées au-delà de l'exécution, ni vendues, ni partagées avec des tiers, ni utilisées pour de la publicité.

L'utilisation des données respecte la Google API Services User Data Policy, y compris les exigences « Limited Use ».

L'accès peut être révoqué à tout moment sur la page des autorisations de sécurité Google.
